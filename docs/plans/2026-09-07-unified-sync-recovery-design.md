# BLACK SPACE 단일 동기화 및 복구 설계

## 목표

메모 저장과 기기 간 동기화를 분리한다. 메모 편집은 인터넷이나 GitHub 인증 상태와 무관하게 각 기기에 자동 저장하고, 톱니 버튼은 노트북·휴대폰·GitHub 간 데이터 차이를 병합하는 하나의 동기화 동작만 수행한다.

## 사용자 경험

- 제목이나 본문 입력을 멈추면 700ms 후 현재 기기의 `localStorage`에 저장한다.
- 포커스 해제, 앱 전환, 페이지 숨김, 앱 종료 직전에는 대기 중인 편집 내용을 즉시 저장한다.
- 톱니 버튼을 짧게 누르면 원격 데이터를 읽고, 로컬 데이터와 병합한 뒤, 병합 결과를 원격에 저장한다.
- 톱니 버튼을 길게 누르면 연결 설정과 복구 메뉴를 연다.
- 일반 사용 화면에서는 `SET`, `PULL`, `PUSH`를 노출하지 않는다.
- 동기화 결과는 짧은 메시지로 성공 또는 오류를 알려준다.

## 복구 흐름

현재 노트북과 휴대폰에 서로 다른 미동기화 메모가 있으므로 원격 파일을 바로 덮어쓰지 않는다.

1. 각 기기에서 전체 로컬 DB를 암호화된 `.blackspace-backup` 파일로 내보낸다.
2. 노트북에서 휴대폰 백업을 가져와 기존 `Sync.mergeDb` 규칙으로 병합한다.
3. 병합된 DB를 다시 백업 파일로 내려받아 복구 지점을 만든다.
4. 새 fine-grained PAT와 새 보안키를 입력한다.
5. GitHub 원격 파일의 SHA만 읽고, 기존 암호문을 해독하지 않은 상태에서 병합 DB를 새 보안키로 암호화해 교체한다.
6. 기존 원격 버전은 private Git 저장소 히스토리에 보존한다.
7. 휴대폰에서 같은 새 자격증명을 설정한 후 단일 동기화를 실행한다.

## 데이터 병합 규칙

- 메모와 TODO는 동일 ID끼리 `updatedAt`을 비교해 최신 버전을 선택한다.
- 서로 다른 ID는 모두 유지한다.
- 폴더는 합집합으로 유지한다.
- 삭제 기록(tombstone)은 대상 데이터보다 최신이면 삭제 상태를 유지한다.
- 백업을 가져온 직후에는 GitHub에 자동 업로드하지 않는다. 사용자가 병합 결과를 확인하고 복구 실행을 승인한 뒤에만 원격을 교체한다.

## 자격증명 보관

- PAT와 데이터 암호화 키는 각 기기에 영구 보관해 앱 재실행 후에도 자동 동기화가 가능하도록 한다.
- 원문 PAT와 암호화 키를 `localStorage`에 직접 저장하지 않는다.
- Web Crypto API로 생성한 기기별 키를 IndexedDB에 보관하고, PAT와 데이터 암호화 키는 해당 기기 키로 감싼 암호문만 저장한다.
- GitHub 저장소에는 메모 DB의 암호문만 저장한다.
- 기기 또는 브라우저 프로필에 접근 가능한 공격자와 악성 스크립트까지 완전히 차단할 수는 없다. 이를 줄이기 위해 외부 스크립트를 사용하지 않고 CSP를 적용한다.

## 구성 요소

- `sync.js`: DB 정규화와 병합 규칙, GitHub Contents API 호출을 유지한다.
- `src/legacy/legacy-source.html`: 단일 톱니 동작, 길게 누르기 설정 메뉴, 자동저장, 백업 내보내기·가져오기, 자격증명 마이그레이션을 담당한다.
- 신규 자격증명 모듈: IndexedDB 기기 키 생성, 자격증명 암호화·복호화, 초기화 기능을 담당한다.
- 테스트: 자동저장 종료 경로, 단일 동기화 순서, 길게 누르기, 백업 왕복, 병합 보존, 자격증명 복구 실패를 검증한다.

## 오류 처리

- GitHub 읽기 실패 시 로컬 DB와 원격 파일을 변경하지 않는다.
- GitHub 쓰기 충돌(409) 시 최신 SHA를 다시 읽고 한 번만 재병합한다.
- PAT가 유효하지 않으면 로컬 메모를 유지하고 재연결 메뉴를 안내한다.
- 백업 암호가 틀리거나 파일이 손상되면 가져오기를 중단하고 기존 DB를 유지한다.
- 원격 재암호화 전에 자동 로컬 백업을 다운로드한다.

## 디자인 제약

기존 3단 웹 레이아웃과 모바일 메모 중심 레이아웃, 아이콘 크기·위치·색상은 변경하지 않는다. 톱니 버튼의 짧게 누르기 동작만 동기화로 바꾸고, 길게 눌렀을 때 기존 크기의 설정 패널 내부에 복구 항목을 표시한다.

## 완료 기준

- 입력 후 앱을 닫아도 해당 기기에서 메모가 남는다.
- 톱니 버튼 한 번으로 양방향 병합이 완료된다.
- 노트북과 휴대폰의 서로 다른 메모가 모두 보존된다.
- 앱 재실행 후 추가 비밀번호 입력 없이 동기화할 수 있다.
- 기존 웹·모바일 디자인에 시각적 회귀가 없다.
- 테스트, 프로덕션 빌드, 로컬 서버 검증과 GitHub Pages 배포 검증이 모두 통과한다.
